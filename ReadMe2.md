## 🧠 About Me

I'm a **Data Scientist and AI/ML Engineer** focused on transforming data into intelligent, useful, and deployable systems.

I enjoy working at the intersection of:

**Data Science → Machine Learning → Artificial Intelligence → Software Engineering → MLOps**

My work spans the complete lifecycle of intelligent systems:

```text
Problem Definition
      ↓
Data Collection
      ↓
Data Cleaning & Validation
      ↓
EDA & Statistical Analysis
      ↓
Feature Engineering
      ↓
Machine Learning / Deep Learning
      ↓
Evaluation & Experimentation
      ↓
API / Application Development
      ↓
Deployment
      ↓
Monitoring & Optimization
```

My primary areas of interest include:

* 📊 Data Science & Statistical Analysis
* 🤖 Machine Learning & Deep Learning
* 🧠 Generative AI & Large Language Models
* 🔎 Retrieval-Augmented Generation (RAG)
* 🗣️ Natural Language Processing
* 👁️ Computer Vision
* ⛏️ Data Mining
* ⚙️ Automation & Intelligent Workflows
* 🚀 MLOps & Model Deployment
* 🌐 AI-powered Web Applications
* 🔬 Applied AI Research

I'm particularly interested in building systems that are not only accurate in experiments, but also **usable, reproducible, maintainable, and deployable**.
